# One-Star Review of Something Essential

A deadpan one-star review of sleep, in a single line of at most 160
characters, for the make.fun competition
[One-Star Review of Something Essential](https://make.fun/c/u-0xb3e689-one-star-review-of-something-essential-c7234629).

## Run

```sh
python3 main.py
```

Writes the review to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR`
to redirect it for local runs). The program is deterministic: the
same bytes on every run, no trailing newline.
